# Aura Math for Fire TV (Vega OS)

A TV-first front end for Aura Math. The Fire TV app reuses the web app's pure lesson engine and
lesson content from the repository root, and adds a remote-driven screen layer on top.

**Status:** the JavaScript side builds, type-checks, lints and passes its tests on Linux. The
native Vega package has **not** been built, and the app has **not** run on a Fire TV device or a
Vega simulator. See `../docs/hackathon-amazon/04-build-and-test.md` for the evidence levels.

## What it shows

- Home screen with Aura Math branding, a Start learning action and remote instructions.
- Topic list, then lesson list, for the 17 web lessons that use choice or number steps.
- Question screen: large prompt, large choices (or a three-digit picker for number steps),
  a visible focus ring, immediate feedback, a four-step hint ladder (MENU), and a Next action.
- Summary screen with values from the session: questions completed, right first time, hints
  used, topic, and the core completion label.

Remote mapping: Up/Down/Left/Right move focus, OK (`select`) answers or continues, BACK leaves
the current screen (and exits from home), MENU (`menu`) or Info shows the next hint.

## Layout

```
fire-tv/
  index.js, app.json            Vega app entry and name
  metro.config.js               watches ../ so shared src/ and content/ resolve
  react-native.config.js        points the RN CLI at the Vega fork
  src/App.tsx                   remote events -> navigation reducer -> screen
  src/engine/                   TV logic: catalogue, remote keys, digit picker, navigation
  src/screens/, src/components/ TV screens and focus-aware components
  src/generated/lessons.json    snapshot of ../content/lessons (regenerated by the build)
  scripts/                      lesson snapshot, bundle, Hermes compile
  __tests__/                    unit, lesson-integration and render tests
```

Shared with the web app (imported from `../src`, not copied): `core/types.ts`,
`core/runtime.ts`, and the pure topic adapters `angles`, `comparison`, `decimals`,
`fraction-calculations`, `fractions`, `whole-numbers`, `place-value`, `equal-groups`,
`picture-graphs`, `line-graphs`, `pie-charts`, `bar-charts`. Topics that need workbenches or
three.js (`nets`, `symmetry`, `area-perimeter`, `angle-measure`) are deliberately not imported.

## Requirements

- Node.js 22.14 or newer (the Vega React Native fork requires it). Verified with Node 22.22.0.
- npm 10 or newer.
- For the native Vega package only (not yet working here): the Vega SDK (VDK) from
  developer.amazon.com, with `KEPLER_SDK_PATH` pointing at it.

## Install, check, bundle

```sh
cd fire-tv
npm ci
npm run check     # typecheck, lint, unit + render tests
npm run build     # lesson snapshot -> build/index.bundle -> build/index.hbc (Hermes)
```

`npm run bundle` and `npm run hermes` run the two halves separately. The Hermes step uses the
`hermesc` binary shipped in the Vega fork under `node_modules/@amazon-devices/react-native-kepler/sdks/`.
Its log is written to `build/hermesc.log`.

To refresh the lesson snapshot after editing `../content/lessons`, run `npm run sync-lessons`.

## Native packaging and running (not yet verified)

The fork's CLI plugin (`@amazon-devices/kepler-cli-platform`) builds Vega apps through a `vega`
binary found under `$KEPLER_SDK_PATH/bin`. That SDK is downloaded from developer.amazon.com,
which was not reachable from the build environment. Until it is installed, `build-vega` and
`vega run-app` have not been run, no `.vpkg` has been produced, and no `manifest.toml` has been
written. The Vega app manifest must be authored from the official Vega documentation once it is
available.

## Known limitations

- 17 of the 64 lessons in `../content/lessons` run on the TV. P4 `exact` and `multi` steps need
  typed or multi-select input and are out of scope for this first release.
- Lesson content is original, draft and not reviewed by a teacher. The home screen says so.
- Progress is kept only in memory for the current session; nothing is stored between launches.
- No accounts, no network calls and no secrets are used.
