# Aura Math font assets

Two self-hosted Latin upright variable WOFF2 files are bundled. They came from the pinned [Fontsource font-files distribution](https://github.com/fontsource/font-files) at npm package version `5.3.0` (repository `gitHead` `02b28c06b126c852a5b966b44aef777ca923f6f6`). Fontsource metadata identifies the original family source as [Google Fonts Outfit](https://github.com/google/fonts/tree/main/ofl/outfit) v15 and [Google Fonts Atkinson Hyperlegible Next](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegiblenext) v7, both last modified 2025-09-05. **These WOFF2 bytes are Fontsource's subsetted distribution, not a byte-for-byte copy of the first-party TTF files.** The package version, integrity value and individual file hashes below pin the exact shipped assets. No runtime font CDN is used.

The adjacent `OFL-Outfit.txt` and `OFL-Atkinson-Hyperlegible-Next.txt` are the exact `LICENSE` files from those packages, SHA-256 `0e5fcef5d93bfcae273c11c00f0bb453d3b5491860e1ac8b658767b7577c938f` and `474a034e99845062f661855caaa505880d0e9009deddc2727a92795eab374955`. They carry SIL OFL 1.1 and original copyright notices. The observed [first-party Outfit OFL header](https://raw.githubusercontent.com/google/fonts/main/ofl/outfit/OFL.txt) and [Atkinson Next OFL header](https://raw.githubusercontent.com/google/fonts/main/ofl/atkinsonhyperlegiblenext/OFL.txt) name no Reserved Font Name. The installed package licences also name none. Both notices must be copied into and linked from preview and learner outputs.

The two files total 66,288 bytes before transfer compression, below the proposed 120 KB font budget. Fontsource metadata lists Outfit weight axis 100–900 and Atkinson Next 200–800. `src/styles.css` declares exactly those upright ranges with `font-display: swap`; the wordmark is upright. No italic face is loaded because the current live CSS/markup scan found no retained italic use.

`fc-query` found the Latin files cover digits, Latin punctuation, `·`, `×`, `÷`, `–`, curly apostrophes/quotes and `−`. Both omit `←`, `→`, `↗`, `≤`, `≥`, `●`, `✓` and `✳`. The CSS family stacks include Segoe UI Symbol and DejaVu Sans as glyph fallbacks, and two CSS-only decorative symbols were replaced with code-native shapes. The runtime arrow and check marks remain text glyphs; inspect them in browser screenshots and replace with code-native icons where their meaning is essential. On this Linux host, DejaVu Sans's cmap covers all of these checked symbols; availability on other systems depends on their fallback fonts.

Repeat the inventory whenever lessons change: `node scripts/font-audit.mjs --inventory-only`. For a shipped binary, run `fc-query -f '%{charset}' assets/fonts/outfit-latin-wght-normal.woff2 | node scripts/font-audit.mjs --charset-stdin assets/fonts/outfit-latin-wght-normal.woff2` (and likewise for Atkinson). The audit reports missing glyphs; a missing item is acceptable only with a documented, visually inspected fallback or code-native replacement. This is a cmap check, not a readability or accessibility certification.
