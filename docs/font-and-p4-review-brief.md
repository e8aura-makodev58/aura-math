## Review questions

1. Does the font proposal make headings, lesson instructions, controls and mathematical labels consistently readable while preserving the accepted palette and layout? Check licensing, local asset delivery, fallback, glyphs and reflow. A visual preference is not evidence of a universal generational preference.
2. Is the first P4 batch useful and bounded? Check objective placement, representations, worked steps, exact arithmetic and author controls. Distinguish a general revision set from an unknown school's assessment scope.
3. Does implementation cover P4 throughout package validation, catalogue metadata, URL filters, authoring and release tooling without mislabelling legacy content or weakening approval gates?
4. Are the acceptance checks sufficient for genuine interactions and original lessons? Avoid conflating passing software tests with human mathematical/pedagogical approval or demonstrated learning gains.
