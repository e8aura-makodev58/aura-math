## Delivery

Four new original draft packages in existing families: `p4-protractor-bench-read`, `p4-protractor-bench-draw`, `p4-mirror-line-bench`, `p4-shade-to-complete-bench`. Existing saved packages remain unchanged. Additive task values, validators, derived answers, author templates and contextual fields; no schema, core contract or publication policy change.

Protractor: move/rotate a translucent dual-scale dial over a rotated angle; native controls and offset Move/Turn handles; construction arm adjustable on the construction lesson. Watch uses another angle; hint 3 aligns the dial, hint 4 reveals the target. Exact reading remains user entered. Construction assesses the supplementary reading, not copied target degrees.

Symmetry: select a bounded mirror line on a shape and shade the far half of a six-column grid. Keep answer selections synchronised with the existing controls. Undo/reset preserve submission history; ghosts only after requested support. Final transfer steps use an ordinary diagram with no live preview.

Validate malformed specs, independent geometry, author rebuilding, shared lifecycle and complete learner flows. Run typecheck, lint, formatting, all unit tests, package validation, builds/release checks and browser checks where the environment permits. Record actual results and screenshots; no claim of human review or real-device acceptance.

## Implemented outcome

All four packages and their author forms are implemented, with new task values in the existing families. Protractor handles support move, rotation and construction-arm dragging; one drag is one undoable gesture. Symmetry line buttons move between four labelled candidates, while the grid supports tap/keyboard shading and synchronised list controls. No free mirror drag is necessary for these bounded candidates. Reflection previews require hint 2; subsequent questions use the ordinary diagram without the preview. Existing nets code and all 60 older package bytes are unchanged. The library is now 64 lessons / 16 topics.

Final checks: 750/750 unit/DOM tests in 38 files; both builds, lint, formatting, 64-package validation, artifact separation and synthetic release gate pass. The main learner bundle is 202,100 JS bytes and 46,677 CSS bytes; 2D lazy chunks total 13,083 bytes. Artifact checks enforce the main/CSS and separate lazy-2D budgets. There are 0 approved lessons.

Eight generic new-lesson Chromium cases were attempted against a temporary test server, but the browser failed at launch (`sandbox_host_linux.cc:41`, shutdown EPERM). No application assertion or screenshot ran. The new dedicated 19-case browser suite is authored and discovered, not executed. In particular, six-column grid sizes at 320/360px and SVG number readability remain unmeasured; a full-size list route is provided, but that does not certify layout or accessibility. Real devices, zoom, assistive technology and human content approval remain open.
